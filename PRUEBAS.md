# Pruebas con terceros (Sprint 4)

El MVP está listo cuando lo probaron **al menos 3 personas ajenas al equipo** (documento de
diseño, sección 7). Esta guía es para quien prueba y para quien anota.

## Para quien prueba

1. Jugá sin que nadie te explique nada (solo leé el menú). Queremos ver si se entiende solo.
2. Intentá llegar al Kiosco de Don Ramón, a la derecha de todo.
3. Comprá algo en la tienda y terminá la partida.
4. Si morís, reintentá.
5. Al final contestá las preguntas de abajo.

## Para quien anota (mientras mira, sin ayudar)

| Qué mirar | Nota |
|---|---|
| ¿Entendió los controles sin ayuda? (moverse, apuntar, disparar, 1-2-3) | |
| ¿Cuánto tardó en llegar al kiosco de Don Ramón? | |
| ¿Cuántas veces murió? ¿Dónde? | |
| ¿Juntó objetos? ¿Se dio cuenta de para qué sirven? | |
| ¿Entendió la tienda y la inflación? | |
| ¿Se trabó o se cerró el juego en algún momento? | |

## Preguntas al final

1. Del 1 al 5, ¿qué tan difícil te pareció? (1 = muy fácil, 5 = imposible)
2. ¿Qué fue lo más divertido?
3. ¿Qué te molestó o no entendiste?
4. ¿Se nota que pasa en Argentina? ¿Qué agregarías?
5. ¿Los precios de la tienda te parecieron caros, baratos o bien?

## Cómo cargar un bug en Trello (lista "Bugs")

- **Qué pasó:** "El zombie atravesó el tren".
- **Dónde:** "En el andén de abajo, cerca del tercer vagón".
- **Cómo repetirlo:** "Me paré pegado al tren y esperé que viniera un Chorro".
